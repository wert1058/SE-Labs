
Циклические алгоритмы. Задания А1–А4
А1. Тренажёр таблицы умножения
Программа задаёт N случайных примеров с множителями от 2 до 9.
Проверяет ответы, измеряет время решения каждого примера,
выводит общее и среднее время, количество и процент правильных
ответов. При вводе нецелого числа повторяет тот же пример.
А2. Рисование фигур
Программа получает размеры n и m с клавиатуры и с помощью
вложенных циклов рисует прямоугольник, прямоугольный треугольник
из n строк и рамку. Рисование каждой фигуры оформлено функцией,
принимающей размеры и символ.
А3. Анализ потерь сетевых пакетов
Программа принимает строку из 0 и 1 длиной не менее 5 символов.
Единица обозначает доставленный пакет, ноль — потерянный.
Вычисляет общее количество пакетов, количество потерянных,
максимальное число потерь подряд и процент потерь.
По проценту потерь оценивает качество связи.
Используются диапазоны:
0–1% включительно — отличное качество;
больше 1%, до 5% включительно — хорошее;
больше 5%, до 10% включительно — удовлетворительное;
больше 10%, до 20% включительно — плохое;
больше 20% — критическое состояние сети.
А4. Валидатор номеров кредитных карт
Самостоятельная реализация проверки номера карты по алгоритму
Луна. Проверяются допустимые символы, длина от 13 до 19 цифр
и контрольная сумма. Номера из одинаковых цифр отклоняются.
Номер вводится без пробелов и дефисов.
Проверка не подтверждает существование или активность карты.
Запуск
Необходим Python 3. Дополнительные библиотеки не требуются.
Из корневой папки репозитория выполните нужную команду:
python3 Lab_4/A1.py
python3 Lab_4/A2.py
python3 Lab_4/A3.py
python3 Lab_4/A4.py
Каждая программа запускается отдельно. Данные вводятся
в терминале после появления приглашения.
